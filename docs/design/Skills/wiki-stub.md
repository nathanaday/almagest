# wiki-stub

> Plant a stub from a sentence, in the user's words, with no questions. A stub may become anything later: a plan, a topic, a source.

**Use for**: note this, stub this, remember to, idea for later, read this someday, report a bug, add a todo.

**Tools**: `search`, `work` stub. **References**: `references/work.md`.

## Procedure

1. `search` the open stubs and plans for the same idea (`types: [stub, spec]`, `status: [open, started]`). When one matches, offer to add the new words to its `## Notes`, and stop if the user agrees.
2. Call `work` stub: `text` is the user's words as given; `title` is a short name; `tags` are the tags that exist and fit what the request names or the conversation is about, or none; `priority` when the user says one.
3. Say the stub's link in one line.

Ask nothing else. A stub is loose by design; [[spec-write]] and the wiki skills ask the questions when it becomes something.

## Hand off

[[spec-work]], when the user wants to start work now.
