
# thread-stub

> Open a thread from a sentence, in the user's words, with no questions. The first draft's "creating a stub" skill.

**Use for**: note this, stub this, remember to, idea for later, open a thread, report a bug, add a todo.

**Tools**: `search`, `thread` open. **References**: `references/threads.md`.

## Procedure

1. `search` the open stubs for the same work. When one matches, offer to add the new words to its `## Notes`, and stop if the user agrees.
2. Call `thread` open: `text` is the user's words as given; `title` is a short name for the work; `scope` is the repositories or areas the request names or the conversation is about, or empty.
3. Say the stub's link in one line.

Ask nothing else. A stub is loose by design; [[thread-spec]] asks the questions.

## Hand off

[[thread-work]], when the user wants to start now.
